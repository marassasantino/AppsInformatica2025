# Aplicaciones Informáticas - Python y Ciencia de Datos

Este repositorio contiene todo el material y ejercicios de la materia **Aplicaciones Informáticas**, donde aprenderé los fundamentos de la programación en Python, el uso de GitHub para control de versiones, y herramientas básicas de Ciencia de Datos.

## 📘 Contenidos del curso

- Fundamentos de programación en Python
- Control de versiones con Git y GitHub
- Introducción a la programación orientada a objetos
- Análisis y visualización de datos
- Introducción a librerías como `pandas`, `numpy`, `matplotlib`, entre otras

## 🧠 Objetivos

- Escribir scripts en Python que resuelvan problemas reales
- Organizar y versionar proyectos usando GitHub
- Leer, limpiar y analizar conjuntos de datos simples
- Crear visualizaciones básicas para interpretar información

## 🛠 Herramientas

- Python 3.x
- Jupyter Notebooks
- Git / GitHub
- Librerías de Ciencia de Datos:
  - pandas
  - numpy
  - matplotlib
  - seaborn (opcional)
